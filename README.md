# Web ve Mobil Uçuş Takip Sistemi

BLM4581 Ağ Tabanlı Teknolojiler ve Uygulamaları dönem projesi (2026-2027 Güz).
Grup: TRackers — Hakkı Erdem Çelik, Furkan Günel

Kullanıcıların uçuş arayıp seferleri hesabına kaydedebildiği ve uçuşları harita üzerinde canlı takip edebildiği web ve mobil uygulama.

## Klasörler
- `docs/` — kapsam, veri modeli, ekran taslakları, örnek API cevapları
- `api/` — ASP.NET Core API
- `web/` — ASP.NET Core MVC web uygulaması
- `mobile/` — Flutter mobil uygulaması

## Teknolojiler
ASP.NET Core (MVC + API), Flutter, PostgreSQL, SerpApi, ADSB.lol
